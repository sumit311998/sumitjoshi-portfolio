# Sumit Joshi • Portfolio Website

![Website Badge](https://img.shields.io/badge/live-sumitjoshi.dev-0A66C2?style=for-the-badge&logo=github)

> A modern, modular, and mobile-responsive portfolio website built using **Flutter Web**, showcasing my technical expertise, experience, and certifications.

---

## 🧠 About This Project

This is the **official personal portfolio website** of Sumit Joshi — a Cloud Developer at IBM with interests spanning across Python, Flutter, Blockchain, and modern Cloud-native technologies.

Built with a **modular code structure**, the project reflects a high-quality, production-ready Flutter web application optimized for performance, scalability, and maintainability.

---

## 🔍 Tech Stack

| Purpose         | Stack / Tools                |
|-----------------|------------------------------|
| Frontend        | [Flutter Web](https://flutter.dev/web) |
| Deployment      | GitHub Pages + GoDaddy DNS   |
| Icons           | `font_awesome_flutter`       |
| PDF Downloads   | Static Assets                |
| Responsive UI   | Custom LayoutBuilder Logic   |

---

## 🚀 Features

- ✅ **Dark-themed, mobile-first UI**
- ✅ **Modular architecture** with each section handled independently
- ✅ Dynamically loaded content (text & images) from `assets/`
- ✅ **Downloadable Resume** (PDF) hosted locally
- ✅ **Certifications Gallery** (auto-loads from `assets/certifications/`)
- ✅ **Responsive Contact Section** with icon-based links
- ✅ **Scroll-optimized Layout** with fixed home section
- ✅ Lightweight and blazing fast ⚡
